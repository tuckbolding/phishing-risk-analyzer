# phishing-risk-analyzer
phishing risk analyzer for cs101 sbcc

## Run the program

Requires Python 3.

```bash
python3 phishing_risk_analyzer.py
```

Answer each yes/no question about the suspicious email. The program adds
points for warning signs and reports **low**, **medium**, or **high** risk:

- Low: 0-2 points
- Medium: 3-5 points
- High: 6 or more points
